# 哏圖整理

用于整理 `F:\哏圖` 的本地桌面工具。第一版重点是三栏浏览与移动图片。

## 运行

开发运行需要 Node.js。运行 `npm install`，然后运行 `npm start`。

Windows 直接使用：双击 `dist/v0.4.6/哏圖整理-win32-x64/哏圖整理.exe`。请保留该目录中的其他文件，不要只复制 exe。重新打包时运行 `npm run package:win`。程序默认打开 `F:\哏圖`，也可通过环境变量 `PICTURETOOL_ROOT` 指定其他图片根目录；`PICTURETOOL_DATA_DIR` 可指定设置和整理记录目录。

运行 `npm run rebuild:thumbnails` 可为全部图片重建缓存。缓存保存在工作区 `.picturetool/thumbs-v5`，原图不会改动；文件夹封面也读取这份缓存。

## 第一版操作

左右两侧各自浏览文件夹，文件夹卡片双击进入。图片单击选中、双击预览；支持 Ctrl+A 全选、Ctrl 多选、Shift 连选、空白处矩形框选和 Ctrl 追加框选。图片可拖到任一侧的当前文件夹、文件夹卡片或指向文件夹的 Windows 快捷方式卡片，先进入待移动清单，确认后移动。右键图片可设置文件夹图标、在文件夹中显示，或用 Windows 默认图片应用打开。文件夹按台湾注音排序，图片按修改时间从新到旧排列；搜索框可查找根目录下所有文件夹。

右侧按层显示文件夹卡片。点击卡片进入该文件夹，点击上方路径返回任意上级；将卡片拖到中间，即可建立长期保存的传送门。移除传送门不会删除文件夹。在图片区域选中一张图后，点击“设为文件夹图标”，该文件夹的卡片会显示这张图。原图移出该文件夹时，卡片恢复默认图标。

将选中的图片拖到传送门，只加入待移动清单。点击右上角“待移动”核对数量、来源和目标，再确认实际移动。移动前检查目标文件夹是否已有同名文件；发生冲突时不会覆盖。

“整理记录”展示每次确认移动的结果。“查找重复”通过文件大小预筛及 SHA-256 内容指纹查找完全相同的图片，不执行删除。

## 当前范围

第一版没有 OCR、完整备份快照、导入流程和类似 Git 的整理节点操作。这些功能已记录在 `docs/需求与计划.md` 中。当前记录只供查看，不提供恢复。
