# 开发记录

## 2026-11-18 · 第一版

- 项目原目录为空，且不是 Git 仓库。
- 选择 Electron + 原生 HTML/CSS/JavaScript，实现 Windows 本地文件访问和桌面拖放。
- 完成三栏界面、传送门、待移动清单、移动记录和完全相同文件检查。
- `npm run check` 已通过；运行验证与 Git 远端状态以本次最终交付说明为准。

后续对话应先读取 `docs/需求与计划.md`，再检查当前代码和 Git 状态；不要把这里的历史描述当作当前运行状态。

## 2026-11-18 · Windows 双击运行版

- 安装 Electron 运行时和 `@electron/packager`，增加 Windows x64 打包命令。
- 产物是包含 exe 与所需运行文件的目录，用户双击 exe 即可打开，无需在使用时运行命令。

## 2026-11-18 · 启动错误修复

- 用户截图显示 `No handler registered for 'initial'`。原因是窗口先加载页面，之后才注册 IPC 接口；页面初始化请求抢先发出。
- 改为注册全部接口后再加载页面，并移除 Electron 默认英文菜单。

## 2026-11-18 · 大量图片启动优化

- 用户截图显示根目录 1378 张图片时缩略图区域显示异常，启动时资源消耗高。
- 图片列表改为每批显示 60 张，缩略图同时最多处理 2 张；选择图片时不再重建整个列表。
- 目录树改为逐层读取，图片列表不再为每张图片单独读取文件属性。
- 缩略图缓存到工作区 `.picturetool/thumbs`；若程序移出工作区则使用应用用户数据目录。缓存由原图路径、大小和修改时间决定，不改动原图。

## 2026-11-18 · 缩略图比例与浏览方式

- 用户反馈缩略图变形，且启动速度已足够快，要求取消分批显示。
- 缩略图按原图宽高比缩小，最大不超过 240 × 180；新结果存入 `.picturetool/thumbs-v2`，避免读取旧版变形缓存。
- 当前文件夹图片一次列出，仍只为接近视口的图片生成缩略图，同时最多处理两张。

## 2026-11-18 · 完整目录树

- 用户反馈目录树只显示部分文件夹。原因是上一版按需读取子目录，未展开的目录既不可见也无法搜索。
- 保持首屏快速显示，同时在后台读取完整目录树；读取完成后默认展开所有层级，文件夹搜索覆盖完整树。

## 2026-11-20 · 文件夹卡片与图标

- 用户将右侧改为逐层显示的文件夹卡片，并要求每个文件夹可选择其中一张图片作图标。
- 后续补充要求：原图移走后恢复默认图标。因此封面设置保存原图路径，不复制独立封面；文件移动时清理对应设置。
- 点击卡片进入下一层，通过顶部路径返回上级；卡片仍可拖至传送门区域。
- 传送门也使用所选文件夹图标；在临时图片目录中验证卡片、传送门显示图标，移动原图后两处恢复默认，并清理临时目录。

## 2026-11-20 · 图片预览与缩略图

- 左侧增加固定的当前层文件夹卡片；图片名称默认隐藏，点击打开应用内预览，右键提供在文件夹中显示和用默认图片应用打开。
- 文件夹和图片使用 `zh-Hant-TW-u-co-zhuyin` 排序；使用 Sharp 生成较高分辨率的缩略图，缓存版本更新，以覆盖旧的低清晰度缓存。
- 预览改为全窗口覆盖，使用项目指定的左右 SVG 按钮；支持滚轮缩放、拖动平移与点击图片外区域关闭。打包时解包 Sharp 的 DLL 和原生模块。

## 2026-11-20 · 双栏文件夹整理

- 根据用户反馈暂时关闭传送门界面，左右两侧改为独立文件夹浏览，支持跨栏拖动进入待移动清单。
- 图片改为单击选中、双击预览；增加 Shift 连选、Ctrl 多选、空白处矩形框选及 Ctrl 追加框选。
- 预览背景使用半透明黑色。交互验证交由用户进行，本次仅做代码检查和打包启动检查。
